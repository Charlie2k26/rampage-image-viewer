# Image Viewer

Ask: “Use Image Viewer to open this image.”

Reuses one packaged template for SVGs and raster images. Click to comment, hold the left mouse button and drag to draw, or right-click to send all comments to chat. New images start with clean comments. SVGs include Preview, Code, Copy source and Download SVG.

Requires Codex inline visualizations (visualize skill) and Python 3. Raster handling requires Pillow; HEIC conversion uses macOS sips when needed. The source image is preserved.
